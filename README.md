The CyberLab is a project I took on alongside my first co-op placement, building an isolated home lab on the NAS on our enterprise-grade home network. I created this home lab with the aim of using it in CTF competitions, learning about the fundamental concepts of cybersecurity, practicing penetration testing techniques, and experimenting with malware in a safe environment. This project was completed with the use of Claude not as an assistant, but as a guide and teacher, walking me through how to set up everything I needed and encouraging me to think about problems like which network policies and how to manipulate web-application vulnerabilities myself instead of just doing them for me.

This required me to learn how to add new devices and zones to the network and how to properly configure communication policies, ensuring that the Lab could only interact with everything that it absolutely needs to as otherwise I could potentially be transmitting unwanted files onto our family devices. Once the lab was set up, I took the time to use it to learn about packet capturing with WireShark, OSINT through a TryHackMe course (which also simulated how the Lab would work in a CTF environment), and web application penetration testing by finding vulnerabilities on a constructed target web application and creating professional write-ups for each one.

The main purpose of this repo is to show you some of the work I've done on this project, namely the write-ups I did following each vulnerability I found in the application - while I wish I could upload the Lab itself, this would be an incredible security risk given that it runs on the NAS in our household. Going forward, I'd like to start using this lab to compete and practice for CTF competitions, and I'd also like to see if there's a way I can share the inner mechanisms of the lab itself on this repo without compromising anything on our network.
