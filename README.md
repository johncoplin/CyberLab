The CyberLab is a project I took on alongside my first co-op placement, building an isolated home lab on the NAS on our enterprise-grade home network. I created this home lab with the aim of using it in CTF competitions, learning about the fundamental concepts of cybersecurity, practicing penetration testing techniques, and experimenting with malware in a safe environment. 

This required me to learn how to properly configure new devices and communication policies on the network, ensuring that the Lab could only interact with everything that it absolutely needs to. Once the lab was set up, I took the time to use it to learn about packet capturing with WireShark, OSINT through a TryHackMe course (which simulated how the Lab would work in a CTF environment), and web application penetration testing by finding vulnerabilities on a constructed target web application.

The main purpose of this repo is to show you some of the work I've done on this project, namely the write-ups I did following each vulnerability I found in the web application.
