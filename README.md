The CyberLab is an isolated home lab hosted on the NAS on our enterprise-grade home network. I created this home lab with the aim of using it in CTF competitions, practicing using cybersecurity tools like Burp Suite, and experimenting with malware in a safe environment. 

I had to learn how to properly configure new devices and communication policies on the network, ensuring that the Lab could only interact with everything that it absolutely needs to. Once the lab was set up, I took the time to use it to learn about packet capturing with WireShark, OSINT through a course which simulated how the Lab would work in a CTF environment, and penetration testing by finding vulnerabilities on a constructed target web application.

The main purpose of this repo is to show you some of the work I've done on this project, namely the write-ups I did following each vulnerability I found in the web application.
